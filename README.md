# Osobní stránka

Na stránce mám informace o sobě, moje projekty, dovednosti
a kontakt.

## Media rules

- min-width – Stránka se přizpůsobuje velikosti okna, aby fungovala i na mobilu.
- prefers-color-scheme – Barvy se mění podle toho jestli má uživatel světlý nebo tmavý režim.
- prefers-contrast – Zvýší se kontrast textu a zvýrazní rámečky pro lepší viditelnost.
- prefers-reduced-motion – Vypnou se animace a přechody aby uživateli nevadil pohyb.
- prefers-reduced-transparency – Vypne se průhlednost karet pro lepší čitelnost.
- forced-colors – Použijí se systémové barvy aby byly vidět rámečky a focus.
- Kombinace – Při zapnutí tmavého režimu a vyššího kontrastu zároveň bude pozadí černé a text bílý.
